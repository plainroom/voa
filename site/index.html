Questions. The short answers.

Is voa really free?

Yes. No subscription, no trial, no account. The code is open source under Apache 2.0. If it helps you, you can buy me a coffee; the app stays the same either way.

Does my mail leave my Mac?

No. voa keeps your mail in a local database on your Mac and talks straight to Gmail, Outlook or your IMAP server. There is no voa server in between.

Which accounts can I add?

Gmail, personal Outlook and Hotmail accounts, and any IMAP server. All of them land in one list, a colored dot for each.

Do I need to set anything up for Gmail or Outlook?

For now, yes, once. voa has no server of its own, so you sign in with your own Google client (about ten minutes, the steps) or your own Microsoft app (about five minutes, the steps). Or skip it: add the account by IMAP with an app password, Gmail included.

Which Macs can run it?

A Mac with Apple silicon. voa is best on macOS 26, where summaries, labels, translation and Speak run on your Mac. It also opens on macOS 12 to 15, with everything else working: one inbox, done, star, remind me, search and writing with Claude.

What do I need for Apple Intelligence?

A Mac with Apple silicon on macOS 26 or later, with Apple Intelligence turned on in System Settings. Summaries and labels run on Apple's on-device model, on your Mac.

Do I need Claude?

No, it's optional. If you have Claude Code on your Mac, ⌘J writes and ⌘⇧J speaks, on your own subscription. voa adds no cloud of its own.

Is it safe to open any mail?

Mail shows in an isolated frame where no script runs, and links open in your browser. If a send might not have gone through, voa tells you and never sends it again by itself.

Can I build it myself?

Yes. Clone the repository, install Node and Rust, and run npm run tauri build. The README has the steps.
